How do I send a ZPL file to the printer?
  • Zebra Setup Utilities (Windows): select the ZD421, click Open Communication With Printer, then Send File and pick the .zpl file.
  • Shared printer on Windows: copy /b vouchers.zpl \\localhost\ZD421 (use your printer's share name).
  • Network printer: send the file to port 9100, e.g. nc 192.168.1.50 9100 < vouchers.zpl.
  • No ZPL tool? Use Print with driver, choose the ZD421, paper size 90 × 50 mm, scale 100%, no margins.

In the print window choose A4, scale 100% (Actual size) and turn on background graphics.
